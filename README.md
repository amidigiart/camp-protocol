# CAMP: Cognitive Arbitration Mediation Protocol

**Author:** Mihai Roșca | **ORCID:** [0009-0001-1422-6209](https://orcid.org/0009-0001-1422-6209) | **Date:** September 2026

## What is CAMP?

CAMP (Cognitive Arbitration Mediation Protocol) is a vendor-neutral protocol for trust verification, conflict resolution, and provenance maintenance across multiple cognitive AI services. It is the referee, not the player.
